# Native documentation

For writing an application, start with [Programming Native](manuals/PROGRAMMING-NATIVE.md).
Its control index links every concrete control to a small program and a
construction sequence. For implementing the library, use the
[Book of Native](manuals/BOOK-OF-NATIVE.md) and the normative
[architecture](standards/ARCHITECTURE.md) and
[C++ style](standards/CPP-CODING-STYLE.md) standards.

| Resource | Use it for |
| --- | --- |
| [Application book](manuals/PROGRAMMING-NATIVE.md) | Step-by-step programs, control selection, layouts, dialogs, deployment |
| [Implementation book](manuals/BOOK-OF-NATIVE.md) | Peers, lifetime, signals, painting, backend adaptations |
| [Feature matrix](manuals/book-of-native/FEATURE-MATRIX.md) | Recorded build/runtime evidence and limitations |
| [Native/custom audit](notes/CUSTOM.md) | Which controls use native widgets, composition, painting, or helpers |
| [AI generation entry point](ai/README.md) | Context loading, generation workflow, request and handoff template |
| [Reusable skills](skills/README.md) | Application construction, control composition, verification |
| [Agent roles](agents/README.md) | Provider-neutral builder, reviewer, and verifier instructions |
| [Exceptional notes](notes/README.md) | Remote hosts, unusual dependencies, open issues and dated reviews |

The [repository contributor brief](../AGENTS.md) maps maintained documents and
states when an implementation change requires a documentation refresh.
